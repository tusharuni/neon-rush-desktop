# NEON RUSH — Desktop Edition

A one-thumb neon arcade dodger, rebuilt for keyboard and mouse play on a wide
landscape screen. Dodge the asteroid storm, chain near-misses, and don't blink.

## Play it

- **Online:** https://neon-rush-space.netlify.app
- **Offline:** download `index.html` and open it in any modern browser — no
  install, no build step. (An internet connection is only needed for the
  display font; the game itself runs fully locally.)

## Controls

| Input | Action |
| --- | --- |
| Mouse | Steer the orb |
| WASD / Arrow keys | Move |
| Space | Dash (short cooldown, brief invulnerability) |
| P | Pause |
| M | Mute |

## How it hooks you

- **Near-miss combo:** grazing an asteroid builds your combo multiplier, up to
  x10, with a decaying combo bar.
- **Rising speed:** the storm gets faster every 10 seconds.
- **Coins and shop:** collect coins and spend them on orb trails and skins —
  saved in your browser.
- **Power-ups:** shield, coin magnet, and slow-mo.
- **Daily missions:** survive 60 seconds, collect 10 coins, reach a x5 combo.
- **Best score:** your best is saved, and the game-over screen tells you
  exactly how many points you were from beating it.

## Files

- `index.html` — the entire game: canvas rendering, synthesized WebAudio
  sound effects, and all game logic in one file. No external assets.
